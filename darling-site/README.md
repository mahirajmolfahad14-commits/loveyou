# Darling — a one-page love poem

Stack: Next.js 14 · React 18 · TypeScript · Framer Motion · GSAP + ScrollTrigger · Lenis · three.js via react-three-fiber (custom GLSL).

    npm install
    npm run dev        # http://localhost:3000
    npm run build && npm start

Edit the words in `lib/poem.ts` (poem, title, dedication, sign-off).
Deploy free on Vercel: push to GitHub → import the repo → deploy.
